# Code of Conduct

Be kind, be specific, assume good faith. This is a small project; the bar is
"would you say it to a colleague you respect".

- Critique code and ideas, not people.
- Keep reviews concrete: what, where, why, and ideally how.
- No harassment, no discrimination, no doxxing — including of the fictional
  sample persona's real-world lookalikes, if any.
- Resumes are personal. Never post someone's real content in an issue, and
  never ask for it.

Problems? Email the maintainer privately through the GitHub profile, or use
the private security report link for anything sensitive. Reports are handled
discreetly; the maintainer may warn, edit, or remove as needed.

This document is adapted in spirit from the Contributor Covenant, shortened
to what a one-maintainer template actually needs.
